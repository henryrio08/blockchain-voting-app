# Terms of use

Last updated: October 15, 2026

This application is an educational demonstration of a Solidity voting contract and a browser interface.

## Educational use only

Do not use this application to run a real election or to make decisions that require confidential ballots, verified voter identity, voter eligibility, coercion resistance, or professional security review. The contract has not been professionally audited.

## Blockchain transactions

Transactions are sent to the network configured by the operator. Transactions may be public, irreversible, and may require gas fees. Check the network, contract address, candidate, and transaction details before approving a request in MetaMask.

Gas sponsorship is optional and depends on a third-party policy. A sponsorship request may be rejected or the user may still need to pay gas.
